# Источники промежуточного доклада

1. **Слайд 1, задача.** Векторная квантизация уменьшает логическое хранение весов. Выигрыш скорости не измерен; размер checkpoint и логическая битность различаются.
2. **Слайд 2, схема DiT.** Peebles, Xie, *Scalable Diffusion Models with Transformers*, ICCV 2023: [статья, раздел 3 и таблица 1](https://arxiv.org/html/2212.09748v2). DiT-XL/2 содержит 28 блоков, разбивает латент на патчи 2×2 и использует adaLN-Zero для условия по времени и классу. Схема упрощена: не показаны позиционные эмбеддинги, residual-связи и детали финального слоя. Число квантуемых матриц 140 относится к нашему срезу [results.json](../data/results.json).
3. **Слайд 3, аддитивное представление.** Egiazarian et al., *Accurate Compression of Text-to-Image Diffusion Models via Vector Quantization*, NeurIPS 2024: [статья, разделы 3–4](https://arxiv.org/html/2409.00492v1). Суммируются векторы из нескольких кодбуков; M=4, K=256, d=8 и полная битность взяты из [results.json](../data/results.json). Выразительность суммы — мотивация метода; собственное сравнение одного и четырёх кодбуков при одинаковой полной памяти не заявляется.
4. **Слайд 4, временные кодбуки.** Числа из [temporal_quality.csv](https://github.com/YaguarEgor/diffusion_models_vector_quantization/blob/9d553985ae90bce6f90f0972e26e7f065e889385/diploma/run_summaries/dit_objective_20261103/temporal_quality.csv); постановка и битность из [EXPERIMENTS.md, раздел 6](https://github.com/YaguarEgor/diffusion_models_vector_quantization/blob/9d553985ae90bce6f90f0972e26e7f065e889385/docs/EXPERIMENTS.md#6-временные-кодбуки). Пять окон DDPM50, общие индексы и масштабы, отдельные статистики входов и значения кодбуков. Суммарный бюджет — 1000 обновлений. Публичный числовой срез: [temporal_results.json](../data/temporal_results.json). Наблюдаемое отсутствие выигрыша FID не устанавливает эквивалентность вариантов или неважность времени вообще.
5. **Слайды 5–6, loss и результат.** Зафиксированный [results.json](../data/results.json) содержит параметры калибровки, протокол, метрики и контрольные суммы артефактов. Непосредственный контроль — перенесённая послойная стадия VQDM. Оригинальный VQDM уже содержит глобальную настройку; новая идея дистилляции не заявляется. Отдельного контроля с другим loss и тем же дополнительным бюджетом нет.

Две таблицы относятся к отдельным выборкам генерации. Корректны сравнения строк внутри каждой таблицы. Улучшение 49,3% рассчитано только по паре 15,401847 → 7,814155 из основного числового среза. Пять временных наборов и четыре кодбука в аддитивной сумме — разные оси постановки.

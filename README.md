# Практикум: первая научная статья

Материалы к заданию:

- [Статья](article/main.pdf) · [исходник](article/main.tex).
- [Исходный однослайдный доклад о временных окнах](slides/one_slide.pdf) · [исходник](slides/one_slide.tex).
- [Промежуточная презентация на 3 минуты](slides/intermediate.pdf) · [исходник](slides/intermediate.tex).

В исходниках заполнены пункты задания: цель, главная идея, литература, постановка, решение, эксперимент, результаты и выводы. Старый однослайдник сохранён как исходный доклад о временных окнах.

В репозитории оставлены только эти документы и зависимости их сборки: стиль статьи, библиография, числовые таблицы и тема слайдов. Код исследования и полная история экспериментов находятся в [научном репозитории](https://github.com/YaguarEgor/diffusion_models_vector_quantization).

Для сборки нужны Tectonic и шрифт Arial. Команды выполняются из корня репозитория:

```sh
(cd article && tectonic main.tex)
(cd slides && tectonic one_slide.tex && tectonic intermediate.tex)
```

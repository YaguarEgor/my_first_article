# Практикум: первая научная статья

Материалы промежуточного доклада на **3 минуты**, срез 12 ноября 2026 года.

Тема работы — **векторная квантизация диффузионных трансформеров**: заменить веса компактным приближением, чтобы уменьшить память для их хранения и сохранить качество изображений. Основа представления — сумма векторов из нескольких кодбуков. Статья и основной доклад следуют одной логике: задача хранения весов → устройство DiT → несколько кодбуков → отрицательный опыт с временными окнами → улучшение FID после калибровки по выходу сети. Отдельный однослайдник сосредоточен на последнем опыте.

Векторная квантизация задаёт компактное представление весов и процедуру его настройки. Реконструкция выхода сети — выбранная цель калибровки. В этом опыте эталонные ответы даёт исходная полноточная модель, поэтому loss также использует дистилляционный сигнал. Это характеристика обучающей цели внутри метода квантизации.

## Результат одной проверки

DiT-XL/2, ImageNet256, **DDPM50**, CFG 1.5, MSE VAE, по 10 000 изображений, согласованные классы и парные шумы, официальный ADM.

| Модель | Логическая битность всей DiT | FID ↓ | sFID ↓ | IS ↑ | Precision ↑ | Recall ↑ |
|---|---:|---:|---:|---:|---:|---:|
| Исходная DiT | 32 | 6.098 | 21.675 | 253.827 | 0.7904 | 0.6659 |
| Перенесённый VQDM, только послойная калибровка | 4.1501 | 15.402 | 27.601 | 145.312 | 0.6491 | 0.7115 |
| VQDM + глобальная калибровка | 4.1501 | 7.814 | 23.367 | 211.549 | 0.7427 | 0.6770 |

FID снизился на 49.3%. Индексы, масштабы и остальные параметры не менялись. Recall снизился, до FP остаётся разрыв 1.72 FID. Результат относится к одному фиксированному запуску и не оценивает разброс по seed. Битность означает логическое хранение весов, а не размер checkpoint или скорость инференса. Полный VQDM уже включает глобальную настройку; здесь контроль содержит только перенесённую послойную стадию. В исходном числовом срезе вариант с 500 обновлениями кодбуков сохраняет историческое обозначение `KD500`.

## Статья по списку требований

В статье явно заполнены: цель и главная идея, литература, постановка задачи с гипотезой и критериями, решение со свойствами и пошаговым алгоритмом, эксперимент, анализ ошибки, таблицы «модель — данные — критерии» и вывод. [Соответствие пунктам задания](REQUIREMENTS.md).

Временное окно — десять последовательных шагов из пятидесяти шагов генерации. Всего пять окон, каждому соответствует собственный набор кодбуков. Архитектура модели остаётся той же; при переходе к следующему окну выбираются другие значения кодбуков. У общего варианта один набор используется на всех шагах. Временной опыт дал FID 15,695 против 15,644, а полная битность выросла с 4,1501 до 4,2588. Это отдельное сравнение, с другой выборкой генерации, чем таблица выше.

## Структура промежуточного доклада

Основной доклад построен вокруг задачи и хода исследования:

1. Титул и задача: уменьшить память для весов DiT, сохранив качество изображений; объяснение термина «квантизация».
2. Краткое введение: схема DiT, квантуемые матрицы и критерий FID.
3. Идея аддитивной квантизации: несколько кодбуков для группы весов.
4. Первая гипотеза: отдельные кодбуки для временных окон. При одинаковом суммарном числе обновлений FID не улучшился, память выросла.
5. Вторая гипотеза: после послойной квантизации калибровать кодбуки по выходу всей сети; параметры опыта и неизменность битности.
6. Общие данные и протокол, таблица метрик, результат и ограничения.

Однослайдовая версия хранится отдельно. Текст выступления рассчитан на весь доклад, а не на чтение каждой формулы. Основные слайды содержат суть и ключевые числа; точные функции потерь, настройки обучения, библиография и ограничения вынесены в статью, текст выступления и файл источников.

Четыре кодбука в аддитивной сумме и пять временных наборов — разные вещи. Отдельное сравнение одного и четырёх кодбуков при одинаковой полной битности здесь не заявляется. Две числовые таблицы относятся к разным выборкам генерации; сравнения проводятся внутри каждой. Отрицательный результат не означает, что время неважно вообще.

## Разделение репозиториев

Этот репозиторий содержит статью и материалы учебного практикума. Исследовательский код, полная научная история и прочие доклады остаются в [diffusion_models_vector_quantization](https://github.com/YaguarEgor/diffusion_models_vector_quantization). Там сохраняется и научная сводка этого опыта. Старый вариант статьи находится в архиве здесь и не подменяет актуальный результат KD500. Статья, PDF и однослайдник сохранены побайтно. Из вспомогательного JSON удалены служебные идентификаторы и пути; научные числа не изменены, что зафиксировано в manifest.

Публикуются компактные научные измерения и контрольные суммы. Веса, ImageNet, окружения и служебные данные кластера не входят в набор артефактов.

## Сборка

Нужны Python 3 и [Tectonic](https://tectonic-typesetting.github.io/) либо XeLaTeX/BibTeX. Для русских слайдов нужен Arial. Сначала генерируются таблицы из `data/results.json` и отдельного исторического среза `data/temporal_results.json`, затем PDF:

```bash
python3 scripts/build.py
# или
python3 scripts/build.py --engine xelatex
```

Можно передать абсолютный путь через `--engine`. Исторический вариант статьи собирается отдельно из `archive/pre_kd_draft` и относится к прежней диагностической постановке. Скрипт сборки пересоздаёт таблицы и документы; он не запускает новое обучение DiT.
